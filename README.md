# DPD research

Исследование цифрового предыскажения (DPD) OFDM-сигнала в MATLAB. Цель работы — компенсация нелинейных искажений усилителя мощности и сравнение двух архитектур обучения: DLA и ILA.

Предыскажатель изменяет сигнал перед усилителем так, чтобы выход каскада DPD–PA был ближе к линейно усиленному исходному сигналу. Результат оценивается по спектру, излучению в соседних каналах и ошибке восстановления сигнала.

## Алгоритмы DPD

**DLA (Direct Learning Architecture), прямое обучение.** Коэффициенты предыскажателя обновляются по ошибке между выходом каскада DPD–PA и эталонным сигналом с заданным усилением. В стенде для расчёта обновлений используются производные модели PA, регуляризация и подбор шага. Таким образом, обучение непосредственно направлено на уменьшение ошибки всего каскада.

**ILA (Indirect Learning Architecture), косвенное обучение.** По выходу PA с учётом опорного усиления обучается обратная модель, которая восстанавливает сигнал на входе усилителя. Её коэффициенты затем переносятся в предыскажатель перед PA. Обучение выполняется по блокам с регуляризацией Тихонова и проверкой предлагаемых обновлений.

В обоих вариантах используется GMP-предыскажатель. Кандидаты обновлений проверяются на контрольных сигналах; отслеживаются качество компенсации и ограничения на сигнал. Обучение и оценка выполняются в моделировании, без подключения аппаратного передатчика.

## Характеристики стенда

- OFDM 16-QAM: канал 5 МГц, частота дискретизации 30,72 МГц, циклический префикс и WOLA.
- Усилитель: GMP-модель с коэффициентами, идентифицированными по измеренным входу и выходу PA.
- Интерполяция в 24 раза до 737,28 МГц и обратная децимация с КИХ-фильтрацией.
- Канал с аддитивным белым гауссовским шумом (AWGN).
- Спектр методом Welch, ACLR, EVM, NMSE, PAPR, созвездия, AM/AM и AM/PM.

Модель PA здесь служит объектом для исследования DPD. Выбор и сравнение моделей усилителя, включая дальнейшие эксперименты с радиальными базисными функциями, планируется оформить в отдельном репозитории. Вспомогательные файлы исследования PA и код CFR пока сохранены для совместимости стенда.

## Запуск

Откройте папку репозитория в MATLAB. Основные алгоритмы QAM, AWGN, Welch и фильтрации реализованы в проекте. В комплекте есть `paModel.mat` с коэффициентами PA и параметрами их применения, без исходных измеренных сигналов.

Запуск с DLA:

```matlab
project = main(config('direct', false), 7);
```

Запуск с ILA:

```matlab
project = main(config('indirect', false), 7);
```

Для сравнения с трактом без DPD:

```matlab
cfg = config('direct', false);
cfg.dpd.enabled = false;
project = main(cfg, 7);
```

Отдельное сравнение обучения DLA и ILA на общих наборах сигналов:

```matlab
[results, summaryTable] = dpdLearningCompareRun(config('direct', false));
```

Во всех примерах CFR отключён вторым аргументом `false`. Вызов `config()` без аргументов использует текущие настройки, где CFR включён. При включённой адаптации или отсутствии совместимой модели DPD запускается обучение; оно может занимать значительное время. Коэффициенты и результаты сохраняются локально в MAT-файлы.

Исходные измерения PA в репозиторий не включены. Для приведённых запусков достаточно готового `paModel.mat`; повторная идентификация усилителя не требуется.

Публикационная копия проверена в MATLAB R2017b: пройдены `dpdSelfTest`, `cfrSelfTest` и запуск полного OFDM-кадра через PA и канал без DPD и CFR. Полное обучение DLA/ILA при подготовке публикации повторно не запускалось.
