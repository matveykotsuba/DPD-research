# DPD research

Исследовательский MATLAB-стенд для моделирования усилителя мощности (PA) и цифрового предыскажения (DPD) OFDM-сигнала.

В проекте сравниваются модели усилителя, исследуется выбор их структуры и оценивается компенсация нелинейных искажений с помощью DPD.

## Что реализовано

- OFDM 16-QAM: канал 5 МГц, частота дискретизации 30,72 МГц, циклический префикс и WOLA.
- Модели PA: Memoryless, Memory Polynomial (MP) и Generalized Memory Polynomial (GMP).
- Идентификация коэффициентов по измеренным входу и выходу усилителя с регуляризацией Тихонова.
- Исследования степени полинома, глубины памяти, числа боковых диагоналей GMP, чётных и нечётных степеней.
- DPD с прямым обучением (DLA) и косвенным обучением (ILA).
- Интерполяция до 737,28 МГц и обратная децимация с КИХ-фильтрацией; отдельные эксперименты по передискретизации и алиасингу.
- Оценка PSD, ACLR, EVM, NMSE, PAPR, созвездий, AM/AM и AM/PM.

Основная тема репозитория — PA и DPD. Код CFR сохранён, поскольку связан с генератором сигнала и проверками совместимости DPD. Отдельное исследование CFR планируется вынести в другой репозиторий. В примерах ниже CFR отключён явно; вызов `config()` без аргументов использует текущие настройки, где CFR включён.

## Запуск

Откройте папку репозитория в MATLAB. Основные алгоритмы QAM, AWGN, Welch и фильтрации реализованы в проекте. В комплекте есть `paModel.mat` с коэффициентами PA и параметрами их применения, без исходных измеренных сигналов.

Публикационная копия проверена в MATLAB R2017b: пройдены `dpdSelfTest`, `cfrSelfTest` и запуск полного OFDM-кадра через PA и канал без DPD и CFR. Полное обучение DLA/ILA при подготовке публикации повторно не запускалось.

Тракт с усилителем, без DPD и CFR:

```matlab
cfg = config('direct', false);
cfg.dpd.enabled = false;
project = main(cfg, 7);
```

Тракт с DPD, без CFR:

```matlab
project = main(config('direct', false), 7);
```

Для ILA замените `'direct'` на `'indirect'`. При отсутствии совместимых коэффициентов DPD запускается обучение. Оно может занимать значительное время. Модели и результаты сохраняются локально в MAT-файлы.

Самотесты:

```matlab
dpdSelfTest();
cfrSelfTest();
```

## Исследования

| Файл | Назначение |
| --- | --- |
| `paModelSelectionRun.m` | Выбор структуры Memoryless и MP; выбор диагоналей GMP при степени и памяти, найденных для MP |
| `paModelCompare.m` | Сравнение трёх моделей с параметрами, выбранными для каждой модели |
| `paFit.m` | Идентификация PA и сравнение МНК с регуляризацией Тихонова |
| `paPolynomialRun.m`, `paMemoryRun.m`, `paDiagonalRun.m` | Отдельные исследования степени, памяти и диагоналей |
| `paParityRun.m`, `paParitySpectrumRun.m` | Сравнение всех степеней с нечётными |
| `dpdLearningCompareRun.m`, `dpdCompareRun.m` | Исследования DPD |
| `amplitudeRun.m`, `snrRun.m` | Метрики при изменении уровня сигнала и SNR |
| `rateConversionExperimentRun.m`, `fftRun.m` | Передискретизация и анализ спектра |

Для повторной идентификации нужны измеренные пары вход/выход. Исходные `122M_dpd_775.mat`, `seed_0.mat` и `seed_1.mat` в репозиторий не включены. Скрипты поиска структуры по умолчанию ожидают `122M_dpd_775.mat` рядом с кодом; большинство принимают путь к файлу аргументом.

```matlab
selection = paModelSelectionRun('122M_dpd_775.mat');
results = paModelCompare('122M_dpd_775.mat', selection);
paFit('122M_dpd_775.mat');
```

`paFit` перезаписывает локальный `paModel.mat`. Загрузчик измерений ожидает поля `signal_in`/`signal_out` либо `txSignal`/`rxSignal` и пять последовательных повторений одного входного сигнала. Четыре выходных повторения используются для обучения, пятое для валидации. Значения валидации используются при выборе параметров и не являются оценкой на независимом тестовом наборе.
